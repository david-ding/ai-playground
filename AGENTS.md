# AI playground

## Background

This project is a series of experiments I'm running as proof of concepts to solve a real production problem for a travel insurance company, where we have a white label solution that's being rolled out to 50 partners.

The main problems that we are trying to solve are:
- How do we minimise changes required when rolling out to a new partner, assuming we are following a certain design system
- How do we have confidence in our changes, both in terms of functionalities and visuals, that they don't cause problems for any other partners.

## Agent behaviour
- Although only 2 brands exists in this project, make sure all solutions would scale to 50 brands.
